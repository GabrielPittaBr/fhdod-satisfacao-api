# Node 26 na API

21/11/2026 · Agente (Claude Code)

> Pendência do [registro 02](2026-11-21-02-fundacao-da-api.md), do ticket [02](../tickets/02-fundacao-da-api.md). O time pediu a versão LTS mais recente do Node.

## O que foi feito

- `.nvmrc` com `26` e `engines.node` em `^26.13.0`.
- `@types/node` 26, a mesma versão do front.
- Build do tsup com alvo `node26`.
- README e "Comandos do projeto", no `AGENTS.md`, falando em Node.js 26.

## Decisões e por quê

| Decisão | Por quê |
| --- | --- |
| Node 26 | É o LTS ativo desde outubro de 2026, com suporte até abril de 2029. O 24 já está em manutenção |
| Mínimo `^26.13.0` | A 26.13.0 foi a primeira versão LTS do 26 (28/10/2026); as anteriores eram da linha "Current" |
| `engines` só avisa, sem `engineStrict` | Quem ainda estiver no Node 24 consegue instalar e vê o aviso do pnpm. A versão de verdade vem do `.nvmrc` (CI) e, no ticket 19, do Dockerfile |

## Ferramentas e skills usadas

- Claude Code. As versões vieram do índice de versões do nodejs.org.
- A máquina de desenvolvimento tem o Node 24. Para conferir, foi usado o Node 26.13.1 oficial, em zip, com o SHA-256 conferido e sem instalar no sistema. Nele passaram `pnpm install`, lint, tipos, os 52 testes (contra o `prisma dev`, como no registro 02), o build e a API rodando com o `/api/health`.
- Nenhuma skill.

## O que mudou em relação ao plano

- Nada: o plano pede "Node.js LTS (22 ou mais recente)".

## Pendências e dúvidas

- **Node local.** Quem estiver no Node 24 precisa instalar o 26, pelo instalador do nodejs.org ou com `nvm install 26`.
- **Front.** O ticket 02 do front pede a mesma versão do Node da API, agora o 26.
- **Dockerfile (ticket 19).** Usar a imagem `node:26-alpine`.
